# Руководство по работе с репозиторием

## Структура проекта

- В `RFVKLauncher/src/` находится код лаунчера на C++17, включая контроллер, модели Qt, бэкенды авторизации и хранилище аккаунтов.
- В `RFVKLauncher/qml/` находятся экраны Qt Quick, а в `qml/components/` — общие элементы управления. Иконки и шрифты лежат в `RFVKLauncher/resources/`, скриншоты интерфейса — в `screenshots/`.
- `autologin/` и `proxy/` — отдельные CMake-проекты для Win32. При сборке из корня их 32-битные DLL входят в поставку вместе с лаунчером x64. Сохраняйте совместимость общих заголовков с обеими архитектурами.
- Скрипт `ci/install-qt.ps1` устанавливает Qt для релизной сборки в `.github/workflows/release.yml`.

## Сборка и запуск

Откройте консоль разработчика Visual Studio для x64. Для сборки нужны инструменты MSVC x64/x86, CMake 3.21+, Ninja в `PATH` и Qt 6.5+ для MSVC x64. Подставьте путь к установленному Qt.

```bat
cmake -S . -B out/build/release -G Ninja -DCMAKE_BUILD_TYPE=Release "-DCMAKE_PREFIX_PATH=C:/Qt/6.11.2/msvc2022_64"
cmake --build out/build/release
cmake --install out/build/release --prefix out/dist
set "RFVK_BACKEND=stub"
out\dist\RFVKLauncher.exe
```

Команда `cmake --install` копирует исполняемый файл, DLL и библиотеки Qt в `out/dist/`. Чтобы вернуться к бэкенду VK Play, сбросьте `RFVK_BACKEND` командой `set "RFVK_BACKEND="`.

## Стиль кода

Используйте отступы в четыре пробела в C++ и QML. Размещайте скобки и выбирайте имена по образцу соседнего кода. Используйте PascalCase для типов C++ и файлов компонентов QML, lowerCamelCase для методов и свойств QML и префикс `m_` для полей классов C++. Используйте `Theme.qml` для оформления, `Strings.qml` для русских текстов интерфейса и переиспользуйте общие элементы управления. Форматтер и обязательная проверка линтером в репозитории не настроены.

## Тестирование

Автоматизированных тестов и требований к покрытию нет. Соберите проект и по возможности проверьте изменённый сценарий вручную с бэкендом-заглушкой. При изменении интерфейса аккаунтов проверьте выбор аккаунтов и изменённое действие в обеих темах. Изменения, которые зависят от GameCenter или игрового клиента, проверяйте в соответствующей среде. Исключайте экспортированные рабочие сессии и учётные данные из коммитов и скриншотов.

## Коммиты и пул-реквесты

Пишите короткие и содержательные заголовки коммитов. В недавних коммитах часто встречаются формулировки с глаголом, например «Улучшить перетаскивание аккаунтов», или префиксы вроде `CI:`. В пул-реквесте кратко опишите, что изменилось и как вы это проверили. Если есть связанные задачи, добавьте ссылки. Для видимых изменений интерфейса приложите скриншоты.
